# AI-Infra

클라우드·인프라 엔지니어 직무를 공부한 걸 모아 두는 저장소예요.

## 시작점과 목표

Linux, 네트워크, 클라우드는 써 보고 조금 공부해 본 정도에서 출발해요.
클라우드, 인프라, DevOps, MLOps 쪽으로 넘어가는 게 1차 목표이고, 길게 보면 이 분야에서 5년차 엔지니어만큼의 실력을 갖추는 게 목표예요.

처음 보는 용어가 많아서, 용어는 나올 때마다 쉽게 풀어서 적어 두려고 해요.
내용은 `로드맵` 폴더에 주제별 마크다운 파일로 나눠 두었고, `00-목차.md`에서 전체 목차와 각 파일 링크를 볼 수 있어요.

## 여기서 다루는 것

### 1. 직무 이해
클라우드 엔지니어, 인프라 엔지니어, SRE, DevOps 엔지니어, 플랫폼 엔지니어, MLOps 엔지니어가 서로 뭐가 다른지부터 정리했어요.
각 직무가 실제로 하루에 하는 일, 쓰는 도구, 연봉대, 한국 채용 시장 분위기를 보고, 직무 전환하는 입장에서 어디부터 시작하는 게 나은지도 따져 봤어요.

### 2. 5년차까지 연차별 로드맵
취업 준비기(0년차)부터 5년차까지 단계별로 나눴어요.
연차마다 갖춰야 할 실력, 공부할 기술, 해 볼 프로젝트, 따 두면 좋은 자격증, 회사에서 맡게 될 일을 적고, "이 정도면 다음 단계로 가도 된다" 싶은 체크리스트도 붙였어요.
취업 준비기는 6개월(26주) 기준으로 주 단위 계획까지 세웠어요.

### 3. 기술별 학습 가이드
기술마다 개념 → 공부 순서 → 실습 과제 → 추천 자료 → 면접 단골 질문 순서로 정리했어요.

- Linux: 명령어, 권한, 프로세스, 서비스, 로그, 셸 스크립트
- 네트워크: OSI/TCP-IP, DNS, HTTP/HTTPS, 로드밸런서, VPC, 방화벽
- 클라우드: AWS 위주로 보고 GCP·Azure와 비교 (EC2, S3, IAM, VPC, RDS, EKS 등)
- 프로그래밍·자동화: Python, Bash, Git
- 컨테이너와 오케스트레이션: Docker, Kubernetes
- IaC: Terraform, Ansible
- CI/CD: GitHub Actions, Jenkins, ArgoCD
- 모니터링·로깅: Prometheus, Grafana, ELK, 알림 설정, 장애 대응
- 보안: IAM 설계, 비밀값 관리, 네트워크 보안
- MLOps: 모델 배포, MLflow, Kubeflow, 데이터 파이프라인, GPU 인프라

### 4. 포트폴리오 프로젝트
쉬운 것부터 어려운 것까지 8개 이상 골랐어요.
프로젝트마다 목표, 쓰는 기술, 진행 단계, 어디까지 하면 완성인지, README에 뭘 적을지를 정리했고, 돈이 거의 안 들게 무료 티어나 로컬 환경에서 해 보는 방법도 같이 적었어요.

### 5. 자격증
AWS SAA, CKA, Terraform Associate, 리눅스마스터, 정보처리기사 같은 자격증의 난이도, 공부 기간, 비용, 취업에 실제로 얼마나 도움이 되는지, 어떤 순서로 따면 좋을지 비교했어요.

### 6. 취업·이직 준비
- 직무 전환자 입장에서 이력서와 포트폴리오 쓰는 법 (예시 포함)
- 스타트업, 중견기업, 대기업, SI, 클라우드 MSP가 각각 어떤 곳이고 어떻게 지원하면 좋을지
- 기술 면접 예상 질문 50개 이상과 답변
- 인성 면접에서 "왜 직무를 바꾸려고 하세요?"에 어떻게 답할지

### 7. 3~5년차에 필요한 실무 역량
장애가 났을 때 어떻게 대응하는지, 포스트모템(장애 회고 문서)은 어떻게 쓰는지, 비용 줄이는 법, 아키텍처 설계, 문서화, 후배 가르치기, 협업까지 연차가 쌓이면 필요한 것들이에요.

### 8. 매일·매주 공부 계획
회사 다니면서 공부할 때와 공부만 할 때, 두 가지 시간표를 따로 짰어요.

### 9. 학습 자료 모음
공부하면서 찾은 자료를 무료/유료, 한국어/영어로 나눠서 모아 두었어요.
