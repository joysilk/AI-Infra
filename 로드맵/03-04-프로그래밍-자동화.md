# 03-04. 프로그래밍·자동화 (Python, Bash, Git)

> 인프라 엔지니어도 코드를 씁니다. "같은 작업을 세 번 하면 자동화"가 기본 정신입니다. 목표는 **알고리즘 고수가 아니라 운영 자동화 도구를 안전하게 만드는 수준**.

## 1. 개념 설명

### 1-1. Bash
- 장점: 어디에나 있고 명령어 연결에 최적. 단점: 복잡해지면 유지보수 어려움 → **50~100줄을 넘으면 Python 고려**.
- 필수 문법: 변수 `"$var"`, 조건 `[[ -f file ]]`, 반복 `for/while`, 함수, 종료 코드(`$?`), `set -euo pipefail`, `trap cleanup EXIT`, 인자 `$1 $@`, 명령 치환 `$(...)`.
- 주의: 따옴표 누락, `rm -rf $VAR/`(변수가 비면 재앙) → `${VAR:?}` 로 방어. `shellcheck` 필수.

### 1-2. Python (운영 자동화용)
- 기초: 자료형(list/dict/set), 제어문, 함수, 클래스 기본, 예외 처리, 파일 I/O, 가상환경(`venv`), `pip`, `pyproject.toml`.
- 인프라에서 자주 쓰는 라이브러리: `boto3`(AWS), `requests`(HTTP), `subprocess`, `argparse/typer`(CLI), `json/yaml`, `logging`, `pytest`, `paramiko`(SSH), `kubernetes` 클라이언트, `jinja2`(템플릿).
- 좋은 습관: 타입 힌트, 로깅(print 대신 logging), 설정은 환경변수/파일, 비밀값 하드코딩 금지, 멱등성(여러 번 실행해도 같은 결과), `--dry-run` 옵션, 테스트.
- 예시(미사용 EBS 볼륨 찾기):
```python
import boto3
ec2 = boto3.client("ec2")
for v in ec2.describe_volumes(Filters=[{"Name":"status","Values":["available"]}])["Volumes"]:
    print(v["VolumeId"], v["Size"], "GB")
```
- Go: SRE/플랫폼 영역에서 점점 중요(쿠버네티스 생태계가 Go). 3년차 이후 선택 학습.

### 1-3. Git
- **Git**: 코드 변경 이력을 관리하는 도구. **GitHub/GitLab**: 협업 호스팅.
- 개념: working directory → staging(`add`) → commit → remote(`push`). 브랜치, merge vs rebase, fast-forward, tag.
- 협업: Pull Request(코드 리뷰 요청), 브랜치 전략(GitHub Flow, trunk-based, Git Flow), 커밋 메시지 규칙(Conventional Commits).
- 복구 도구: `git status/log/diff`, `git restore`, `git revert`(이력 보존 되돌리기), `git reset`(이력 이동, 공유 브랜치에 주의), `git reflog`(잃어버린 커밋 찾기), `git stash`, `git cherry-pick`, `git bisect`(원인 커밋 찾기).
- 주의: **비밀값(키, 비밀번호)을 커밋하지 말 것.** 실수로 올렸다면 키를 즉시 폐기(rotate)하는 것이 먼저. `.gitignore`, `pre-commit`, `gitleaks`/`git-secrets`.

## 2. 공부 순서
1. Bash 기본(Linux 병행) → 2. Git 기본·PR 흐름 → 3. Python 문법 → 4. Python으로 파일/JSON/HTTP → 5. boto3로 AWS 자동화 → 6. CLI 만들기(argparse) → 7. 테스트/린트(pytest, ruff) → 8. 로그/에러 처리/재시도 → 9. (선택) Go 기초.
- 기간: 병행 학습 6~8주.

## 3. 실습 과제
1. Bash: 로그 정리/백업/헬스체크 스크립트 5개, `shellcheck` 통과.
2. Git: 브랜치 생성→PR→리뷰→머지, 충돌 일부러 만들고 해결, `reflog`로 삭제한 커밋 복구, `bisect`로 버그 커밋 찾기.
3. Python: 사이트 상태 체크(URL 목록 → 상태코드/응답시간 → 슬랙 알림).
4. boto3: 태그 없는 EC2 찾기 / 미사용 EBS·EIP 리포트 / 야간 개발 인스턴스 정지 스크립트(`--dry-run`).
5. CLI 도구화: `typer`로 서브커맨드(`report`, `cleanup`) 만들고 README, 테스트 추가.
6. GitHub Actions에서 린트/테스트가 PR마다 돌게.
7. (심화) 쿠버네티스 클라이언트로 재시작 횟수 많은 Pod 목록 출력.
8. (심화) 알고리즘 기본(해시맵, 정렬, 문자열) 30문제 — 코딩테스트 대비 최소치.
