## 주차별 계획

### 페이즈 1: Linux, 셸, Git
**1주차 - 환경 구축과 기본 명령어**
- 목표: 리눅스 VM 준비, 터미널 익숙해지기.
- 할 일: VirtualBox/Multipass/WSL2/UTM으로 Ubuntu 준비, `ls cd cp mv rm find grep cat less tail` 실습, 파이프/리다이렉션, `man`과 `--help` 읽는 습관.
- 결과물: 명령어 치트시트(본인 언어로) 작성.

**2주차 - 사용자·권한·패키지**
- 할 일: `useradd/usermod`, `chmod/chown`, `sudo`, `/etc/passwd`, `apt/dnf`, SSH 키 인증 설정, `sshd_config` 수정.
- 결과물: 비밀번호 로그인 막고 키로만 접속하는 서버 설정 문서.

**3주차 - 프로세스·서비스·로그**
- 할 일: `ps top htop kill systemctl journalctl`, systemd 유닛 파일 직접 작성(간단한 앱을 서비스로 등록), `/var/log`, logrotate, cron.
- 결과물: 직접 만든 앱의 systemd 서비스와 로그 확인 가이드.

**4주차 - Bash 스크립트 + Git**
- 할 일: 변수/조건문/반복문/함수/`set -euo pipefail`, 백업·로그 정리 스크립트 작성. Git: clone/branch/merge/rebase/PR, 충돌 해결.
- 결과물: GitHub 저장소 `linux-practice`에 스크립트 5개 + README.
- 체크포인트: 서버 하나를 열어 웹서버(nginx) 설치→서비스 확인→로그 분석 가능.

### 페이즈 2: 네트워크
**5주차 - OSI/TCP-IP, IP/서브넷**
- 할 일: IP, CIDR, 서브넷 계산 연습 20문제, TCP 3-way handshake, 포트, `ip a`, `ss`, `ping`, `traceroute`.
- 결과물: 서브넷 계산 정리, 패킷 흐름 그림.

**6주차 - DNS, HTTP/HTTPS, TLS**
- 할 일: `dig`, `nslookup`, `curl -v`, 레코드(A/CNAME/MX/TXT), HTTP 상태 코드, 인증서 개념, Wireshark/tcpdump로 직접 패킷 보기.
- 결과물: "브라우저에 URL 입력하면" 설명 글.

**7주차 - 로드밸런서·방화벽·NAT**
- 할 일: nginx로 로드밸런싱, `iptables`/`ufw`, NAT, 프록시 vs 리버스 프록시, Docker 없이 VM 2~3대로 구성.
- 결과물: nginx 로드밸런서 구성 문서 + 실패 시나리오 테스트.

### 페이즈 3: AWS
**8주차 - 계정 보안과 IAM, 비용 관리**
- 할 일: AWS 계정 생성, 루트 MFA, IAM 사용자/역할/정책, Budgets 알림, CLI 설정.
- 결과물: 안전한 계정 초기 설정 체크리스트.

**9주차 - EC2·EBS·S3**
- 할 일: EC2 생성/SSH, 보안그룹, EBS 스냅샷, S3 버킷 정책, 정적 웹 호스팅, CloudFront 개요.
- 결과물: 프로젝트 1 (정적 웹사이트 호스팅) 완성.

**10주차 - VPC 심화**
- 할 일: 퍼블릭/프라이빗 서브넷, IGW, NAT GW, 라우팅 테이블, NACL vs SG, VPC 직접 설계(콘솔).
- 결과물: VPC 다이어그램 + 설명.

**11주차 - ELB, Auto Scaling, RDS, Route53**
- 할 일: ALB 뒤 EC2 2대, ASG 정책, RDS 멀티 AZ 개념, Route53 레코드.
- 결과물: 프로젝트 2 (3-tier 아키텍처) 구축·문서화.

**12주차 - SAA 정리와 모의고사**
- 할 일: Well-Architected 6대 축, 서비스별 사용 시나리오, 모의고사 3회분(오답노트).
- 결과물: SAA 시험 일정 예약(다음 주~3주 내).
- 체크포인트: 모의고사 점수 70% 이상 안정적으로.

### 페이즈 4: Docker, Python
**13주차 - Docker 기초**
- 할 일: 이미지/컨테이너/레이어, Dockerfile, 볼륨, 네트워크, `docker compose`.
- 결과물: 샘플 웹앱 컨테이너화.

**14주차 - Docker 실전**
- 할 일: 멀티스테이지 빌드, 이미지 용량 줄이기, 비루트 사용자, 헬스체크, ECR 푸시.
- 결과물: 프로젝트 3 (Docker 컨테이너화 + compose) 완성.

**15주차 - Python 자동화 + SAA 응시**
- 할 일: boto3로 EC2/S3 조작, 파일/JSON 처리, `requests`, 간단한 CLI. SAA 시험 응시.
- 결과물: 미사용 EBS/EIP 찾는 비용 점검 스크립트.

### 페이즈 5: IaC
**16주차 - Terraform 기초**
- 할 일: provider, resource, variable, output, state, plan/apply/destroy.
- 결과물: EC2 + SG를 Terraform으로.

**17주차 - Terraform 실전**
- 할 일: 모듈, remote state(S3 + 락), workspace/디렉터리 분리, VPC 전체를 코드화.
- 결과물: 프로젝트 4 (Terraform으로 3-tier 인프라) 완성.

**18주차 - Ansible + 정리**
- 할 일: 인벤토리, 플레이북, 롤, 멱등성, nginx 설정 자동화. Terraform Associate 개념 정리.
- 결과물: Ansible 롤로 서버 5대 일괄 설정.

### 페이즈 6: CI/CD
**19주차 - GitHub Actions 기초**
- 할 일: 워크플로 문법, 이벤트, 잡, 시크릿, 캐시, 매트릭스.
- 결과물: 린트+테스트 자동화.

**20주차 - 컨테이너 빌드/배포 파이프라인**
- 할 일: 이미지 빌드→ECR 푸시→EC2/ECS 배포, OIDC로 AWS 인증(키 없이).
- 결과물: 프로젝트 5 (CI/CD 파이프라인) 완성.

**21주차 - Jenkins 맛보기 + 보안 스캔**

### 페이즈 7: Kubernetes, 모니터링
**22주차 - Kubernetes 기초**
- 할 일: kind/minikube/k3s, Pod/Deployment/Service/ConfigMap/Secret, `kubectl`.
