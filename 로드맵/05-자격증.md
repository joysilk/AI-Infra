## 2. 자격증별 상세

### AWS SAA (최우선 추천)
- **내용**: 고가용성·보안·비용·성능을 고려한 AWS 아키텍처 설계 시나리오(객관식 65문항, 130분).
- **공부법**: ① 입문 강의 1개(Stephane Maarek / Adrian Cantrill / 한국어 인프런 강의) ② 콘솔 실습(프로젝트 1~2 병행) ③ Tutorials Dojo 모의고사 반복(오답노트) ④ Well-Architected 6축 ⑤ 서비스 비교(S3 클래스, EBS 타입, ALB vs NLB, RDS vs Aurora 등).
- **합격 팁**: "가장 비용 효율적", "운영 오버헤드 최소" 같은 키워드 패턴. 모의고사 80% 이상 안정적일 때 응시.
- **효과**: MSP·클라우드 직무 서류 통과 신호. 포트폴리오와 병행하면 큰 효과.

### CKA
- **내용**: 실습형 시험(2시간, 실제 클러스터에서 문제 해결). 클러스터 설치/업그레이드, etcd 백업/복구, 네트워킹, 스토리지, 트러블슈팅.
- **공부법**: KodeKloud(Mumshad) 강의+랩 → killer.sh 모의시험 2회(시험 등록 시 포함) → `kubectl` 속도 훈련(alias, `--dry-run=client -o yaml`, 공식 문서 검색 숙련).
- **효과**: 쿠버네티스 직무에서 가장 신뢰받는 신호. 1~2년차에 취득 추천.

### Terraform Associate
- **내용**: 개념·워크플로·state·모듈·HCP Terraform 이해(객관식, 1시간 내외).
- **공부법**: 공식 튜토리얼 + 프로젝트 4 + 모의고사.
- **효과**: 가성비 좋은 IaC 증명. 단, 실제 코드 포트폴리오가 더 중요.

### 리눅스마스터
- **2급**: 입문/기초, 필기+실기. 비전공자에게 리눅스 체계적 학습용으로 좋지만 실무 평가는 제한적. **1급**: 국내 SI/공공/인프라에서 가점. 내용이 오래된 편이라 실무 학습은 별도 필요.
- **추천 대상**: 국내 SI·공공·대기업 전산 타깃 또는 리눅스 체계를 처음 잡을 사람.

### 정보처리기사
- **내용**: 소프트웨어 공학, DB, 네트워크, 보안 등 폭넓은 이론. 직무 직접 연관은 낮으나 **대기업·공공·금융 지원 시 요건/가산점**이 되는 경우가 많음.
- **추천 대상**: 대기업/공공/SI 지원 계획이 있고 시간 여유가 있는 사람. 스타트업·외국계는 우선순위 낮음.
- **참고**: 응시 자격(학력/경력/기사 취득 예정자 등 조건)을 큐넷에서 확인.

## 3. 추천 순서

### 기본 경로 (클라우드/DevOps 지향)
1. (선택, 1~2주) AWS Cloud Practitioner — 용어 익히기용, 건너뛰어도 됨.
2. **AWS SAA** (0년차 목표 1순위)
3. **Terraform Associate** (0~1년차)
4. **CKA** (1~2년차)
5. AWS DevOps Pro 또는 SA Pro (2~4년차, 회사 지원 활용)
6. CKS / Security Specialty (보안 방향) 또는 ML 관련(MLOps 방향)

### 국내 대기업/SI 지향
정보처리기사 → 리눅스마스터 2급(필요 시) → AWS SAA → 리눅스마스터 1급 / CKA

### 인프라(네트워크 포함) 지향
네트워크관리사 2급 또는 CCNA → 리눅스마스터 → AWS SAA → CKA

## 4. 자격증 활용 원칙
- 자격증은 **서류 통과용 신호**이고, 면접에서는 실습·프로젝트 경험이 평가됩니다. "자격증 + 그 내용을 구현한 프로젝트" 세트로 만드세요.
- 회사에서 시험 비용을 지원하는 경우가 많으니 입사 후 활용(교육비/자격증 수당 확인).
- 덤프(기출 암기)만으로 취득하지 않기. 면접에서 바로 드러나고 시험 약관 위반 위험이 있음.
- 연도별 목표 예시: 0년차 SAA / 1년차 Terraform + CKA 준비 / 2년차 CKA / 3년차 AWS Pro 또는 CKS.
- 갱신: AWS 3년, CKA 2년(재응시 또는 상위 자격 취득으로 갱신 정책 확인). 만료일을 캘린더에 등록.
