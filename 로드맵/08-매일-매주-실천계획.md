# 08. 매일·매주 실천 계획

> 핵심: **꾸준함 > 몰아치기**. 이론 40% : 실습 60%. 매주 반드시 "결과물 1개"(커밋/글/스크린샷). 번아웃 방지를 위해 주 1일은 쉽니다.

## 공통 원칙
1. 새 개념은 **반드시 손으로 실습**(보기만 하지 않기).
2. **간격 복습**: 1일/3일/1주/1달 뒤 복습(앱: Anki).
3. **기록**: 블로그/노션에 "삽질 기록". 막힌 문제와 해결 과정.
4. **2시간 규칙**: 같은 오류에 2시간 쓰면 질문/우회.
5. 클라우드 비용 안전: Budgets, 작업 후 삭제 습관.
6. 주간 회고(30분): 한 일 / 막힌 것 / 다음 주 / 일정 조정.
7. 스터디/커뮤니티 1개 참여(동기 유지, 면접 연습).

---

## 버전 A: 직장 다니면서 공부 (주 15~20시간)
> 기간: [02-2](02-2-0년차-26주-계획.md)의 26주 계획을 **약 40~52주(9~12개월)**로 늘려 적용. 목표 9~12개월.

### 평일 (월~금) 예시: 출근 직장인
| 시간 | 활동 |
|---|---|
| 출근길(30~40분) | 강의 시청/개념 복습/면접 질문 1개 암기(오디오·앱) |
| 점심(선택 15분) | 기술 블로그/뉴스레터 읽기 |
| 저녁 20:30~22:30 (2시간) | **핵심 실습 1.5시간 + 정리 30분** (월·수·금: 새 주제 실습 / 화·목: 복습 + 프로젝트) |
| 취침 전 10분 | 오늘 배운 것 3줄 요약(노션) |
- 평일 합계: 약 2.5시간 × 5 = 12시간 (바쁜 날은 30분 최소 목표를 지켜 "연속 기록" 유지)

### 주말
| 요일 | 활동 |
|---|---|
| 토요일 | 4~5시간 블록: 프로젝트 작업(오전) + 블로그/README 정리(오후), 스터디 참석 |
| 일요일 | 휴식(오전) + 1~2시간: 주간 회고, 다음 주 계획, 면접 질문 5개 연습 |
- 주말 합계: 약 6~7시간

### 일 단위 템플릿 (평일)
```
20:30 환경 준비, 오늘 목표 1줄 (예: "VPC 서브넷 + 라우팅 직접 구성")
20:35 개념 학습 30분 (강의/문서)
21:05 실습 60분 (직접 구성, 에러 해결)
22:05 정리 20분 (명령어/삽질/스크린샷 → 노션 or GitHub 커밋)
22:25 내일 할 일 1줄 적고 종료
```

### 월간 구조 (4주 사이클)
- 1~3주차: 주제 학습 + 실습
- 4주차: 프로젝트 통합 + 문서화 + 자격증 모의고사 + 이력서 업데이트
- 분기마다: 자격증/프로젝트 완성 점검, 지원 시작 시점 판단

### 시기별 목표(직장인)
| 기간 | 목표 |
|---|---|
| 1~3개월 | Linux/Git/Bash/네트워크 기초 + 프로젝트 1 |
| 4~6개월 | AWS 집중 + SAA 응시 + 프로젝트 2~3 |
| 7~9개월 | Docker/Terraform/CI/CD + 프로젝트 4~5 |
| 10~12개월 | K8s/모니터링 + 이력서·면접 + 지원 시작(이른 시점부터 병행 지원 권장) |

### 직장인 팁
- 퇴근 후 에너지가 없으면 **강의 시청 대신 실습 위주**, 어려운 개념은 주말로.
- 회사 업무와 연결(자동화 가능한 반복 작업 찾기 → 스크립트화 → 이력서 소재).
- 연차/휴가를 시험·집중 주간에 배치. 시험 일정은 미리 예약(데드라인 효과).
- 번아웃 징후(2주 이상 흥미 하락): 목표를 절반으로 줄이되 연속성 유지.

## 버전 B: 전업 공부 (주 35~45시간)
> 기간: 26주(6개월) 계획 그대로 적용. 체력/집중력 관리가 관건.

### 평일 시간표 (월~금)
| 시간 | 활동 |
|---|---|
| 08:00~09:00 | 기상, 운동/산책, 아침, 어제 복습 15분(Anki/요약 노트) |
| 09:00~10:30 | **이론/강의** (새 주제 개념) — 집중력 높은 시간에 가장 어려운 주제 |
| 10:30~10:45 | 휴식 |
| 10:45~12:30 | **실습 1** (바로 직접 구성/코딩) |
| 12:30~13:30 | 점심 + 휴식 (모니터 떠나기) |
| 13:30~15:30 | **프로젝트 작업** (포트폴리오, README, 다이어그램) |
| 15:30~15:45 | 휴식 |
| 15:45~17:30 | **심화/문제 해결**: 장애 만들고 고치기, 면접 질문, 자격증 문제 풀이 |
| 17:30~18:00 | 오늘 정리(블로그 초안/커밋/내일 계획) |
| 저녁 | 자유(운동, 식사, 휴식). 가벼운 독서/기술 블로그 30분 정도 |
- 하루 실학습 6~7시간(몰입 기준), 총 평일 약 30~35시간.

### 주말
| 요일 | 활동 |
|---|---|
| 토요일 | 오전: 블로그 작성 + 복습 / 오후: 스터디·커뮤니티·모의 면접 / 가벼운 프로젝트 |
| 일요일 | 완전 휴식 또는 2시간 주간 회고 + 다음 주 계획 |

### 주간 리듬
- 월: 새 주제 개념 + 첫 실습 / 화~목: 실습·프로젝트 / 금: 정리·복습·모의고사 / 토: 블로그·스터디·면접 연습 / 일: 휴식·회고
- 4주마다 "통합 주간"(밀린 것 정리 + 이력서/프로젝트 문서화 + 점검).

### 전업 시기별 목표
| 기간 | 목표 |
|---|---|
| 1~4주 | Linux, 셸, Git — 프로젝트 0(스크립트 모음) |
| 5~7주 | 네트워크 — 프로젝트 1~2 일부 |
| 8~12주 | AWS 집중, SAA 응시 |
| 13~18주 | Docker/Python/Terraform/Ansible |
| 19~24주 | CI/CD, K8s, 모니터링 |
| 25~26주+ | 이력서/면접/지원(사실 15주차부터 병행 지원 추천) |

### 전업자 주의
- **고립 방지**: 스터디/커뮤니티/오프라인 모임(AWSKRUG, 쿠버네티스 한국 커뮤니티, DevOps 모임). 주 2회 이상 사람과 대화.
- **생활 리듬/운동/수면** 유지(수면 7시간). 장시간 앉아 있기 방지.
- **재정 계획**: 6~9개월 생활비·교육비·시험비 확보. 일정이 지연되면 아르바이트/단기 계약 병행 판단.
- **공백기 설명 준비**: 이 기간의 학습 결과물(프로젝트/자격증/블로그)을 포트폴리오에 명확히. "무엇을 했는가"를 면접에서 말할 수 있게.
- 완벽주의 금지: 일정이 밀리면 K8s 심화/Jenkins/Ansible을 줄이고 AWS·Terraform·CI/CD·프로젝트 완성도를 지킨다.

## 주간 체크리스트 (복사해서 매주 사용)
```
[ ] 이번 주 목표 3개 정함
[ ] 실습 5회 이상 (직접 구성)
[ ] 결과물 1개 이상 (커밋/글/다이어그램)
[ ] 면접 질문 5개 소리 내어 답변
[ ] 클라우드 리소스 정리 및 비용 확인
[ ] 회고 30분 (한 일/막힌 것/다음 주)
```

## 월간 점검
- 계획 대비 진도(%) / 프로젝트 완성 수 / 자격증 모의고사 점수 / 블로그 글 수 / 지원 현황.
- 진도가 80% 미만이면 범위를 줄이고, 핵심 5요소(Linux/네트워크/AWS/Terraform/CI-CD+Docker)를 우선.
