# 01. 직무 이해

> 연봉은 2024~2025년 한국 채용 공고·커뮤니티 기준의 **대략적 범위**(세전, 연봉 총액)입니다. 회사 규모·지역·성과급에 따라 크게 달라지므로 원티드·사람인·잡플래닛·블라인드 등에서 직접 확인하세요.

## 1. 한눈에 보는 6개 직무

| 직무 | 한 줄 정의 | 핵심 질문 | 주 무기 |
|---|---|---|---|
| 클라우드 엔지니어 | 클라우드 위에 서비스가 돌아갈 환경을 설계·구축·운영 | "이 서비스를 AWS에 어떻게 올릴까?" | AWS/GCP/Azure, Terraform, 네트워크 |
| 인프라 엔지니어 | 서버·네트워크·스토리지(온프레미스+클라우드)를 구축·운영 | "서버가 안정적으로 떠 있나?" | Linux, 네트워크, 가상화, 모니터링 |
| SRE | 서비스 신뢰성(가용성·지연·장애)을 코드와 수치로 관리 | "SLO를 지키고 있나? 장애 재발을 어떻게 막나?" | 관측성, 자동화, 장애 대응, Go/Python |
| DevOps 엔지니어 | 개발→배포 흐름을 자동화하고 개발팀을 돕는다 | "배포를 어떻게 빠르고 안전하게?" | CI/CD, Docker, K8s, IaC |
| 플랫폼 엔지니어 | 개발자가 쓰는 내부 개발 플랫폼(IDP)을 제품처럼 만든다 | "개발자가 셀프서비스로 쓰게 하려면?" | Kubernetes, Backstage, GitOps, Helm |
| MLOps 엔지니어 | ML 모델 학습·배포·모니터링 파이프라인과 GPU 인프라 운영 | "모델을 어떻게 안정적으로 서빙하나?" | Kubeflow, MLflow, GPU, 파이프라인 |

> 용어: **온프레미스**=회사가 직접 보유한 전산실의 서버. **SLO**=서비스 수준 목표(예: 월 99.9% 가용). **관측성(Observability)**=시스템 내부 상태를 로그·지표·추적으로 파악할 수 있는 정도. **GitOps**=Git 저장소 내용을 "정답"으로 삼아 인프라/배포 상태를 자동으로 맞추는 방식.

## 2. 직무별 상세

### 2-1. 클라우드 엔지니어
- **하루**: 아침 알림/비용 확인 → 신규 서비스용 VPC·서브넷·보안그룹 설계 → Terraform 코드 리뷰 → IAM 권한 요청 처리 → 개발팀 문의 대응 → 비용 이상 징후 확인 → 마이그레이션(온프레→클라우드) 작업.
- **도구**: AWS(EC2, S3, VPC, IAM, RDS, EKS, CloudWatch), Terraform, CloudFormation, Python/Bash, Cost Explorer.
- **연봉**: 주니어 3,500~5,000만 / 3~5년 5,000~7,500만 / 시니어 7,000~1억+.
- **채용시장**: 클라우드 전환이 진행 중이라 수요 꾸준. 클라우드 MSP(메가존, 베스핀글로벌, 그로우, 클루닉스, 삼성SDS 클라우드 부문 등)와 일반 서비스 기업에서 채용. 주니어는 MSP를 통한 진입이 흔함.

### 2-2. 인프라 엔지니어 (시스템/네트워크)
- **하루**: 서버 상태 점검 → 패치·보안 업데이트 → 디스크/메모리 용량 관리 → 방화벽 정책 요청 처리 → 장애 티켓 대응 → 백업·복구 점검 → 증설/이전 작업(주로 야간·주말).
- **도구**: Linux(RHEL/Rocky/Ubuntu), VMware, Ansible, Zabbix/Nagios/Prometheus, 스위치/라우터, 방화벽(Palo Alto, Fortinet), 스토리지.
- **연봉**: 주니어 3,000~4,500만 / 3~5년 4,500~6,500만. (SI·대기업 계열사는 편차 큼)
- **채용시장**: 금융권·SI·대기업 전산에서 꾸준하나, 순수 온프레 직무는 서서히 클라우드/자동화 요구로 이동 중. "인프라 + 자동화(Ansible/Terraform)" 조합이 경쟁력.

### 2-3. SRE (Site Reliability Engineer)
- **하루**: 대시보드·SLO 소진율(에러 버짓) 확인 → 온콜(장애 호출 대기) 대응 → 포스트모템(사후 분석) 작성 → 반복 작업(toil) 자동화 → 용량 계획 → 배포 안전장치(카나리, 롤백) 개선.
- **도구**: Prometheus, Grafana, Loki/ELK, OpenTelemetry, PagerDuty/Opsgenie, Kubernetes, Terraform, Go/Python.
- **연봉**: 주니어는 드묾. 3~5년 6,000~9,000만 / 시니어 8,000만~1.3억+.
- **채용시장**: 대형 IT(네이버, 카카오, 쿠팡, 토스, 당근, 배민 등)·유니콘에서 주로 채용. 경력자 위주라 **첫 직무로는 어렵고 DevOps/클라우드/인프라 → SRE 이동 경로가 일반적**.

### 2-4. DevOps 엔지니어
- **하루**: 빌드 실패 원인 분석 → CI/CD 파이프라인 개선 → 쿠버네티스 배포 매니페스트(Helm) 관리 → 개발자 요청 대응 → 스테이징/운영 환경 정합성 확인 → 보안 스캔 도입.
- **도구**: GitHub Actions, Jenkins, GitLab CI, ArgoCD, Docker, Kubernetes, Helm, Terraform, SonarQube, Trivy.
- **연봉**: 주니어 3,500~5,000만 / 3~5년 5,000~8,000만.
- **채용시장**: 스타트업~중견 IT에서 수요 가장 넓음. 공고 이름이 "DevOps"인데 실제론 인프라 전반(서버·클라우드·배포·모니터링)을 다 하는 경우가 많음 → 면접에서 업무 범위 확인 필수.

### 2-5. 플랫폼 엔지니어
- **하루**: 내부 개발 플랫폼(배포 포털, 템플릿, 쿠버네티스 클러스터 표준화) 로드맵 회의 → 개발자 인터뷰/피드백 → 클러스터 업그레이드 → 골든 패스(표준 배포 경로) 개선 → 개발자 문서·온보딩 개선.
- **도구**: Kubernetes, Helm, ArgoCD, Crossplane, Backstage, Terraform, Go.
- **연봉**: 5,500~9,000만+ (경력 중심).
- **채용시장**: 중대형 IT 위주, 비교적 신생 직무명. 보통 DevOps/SRE 경력자가 이동.

### 2-6. MLOps 엔지니어
- **하루**: 모델 서빙 장애 확인 → 학습 파이프라인 실패 분석 → GPU 노드 스케줄링/비용 관리 → 데이터 드리프트 모니터링 → 모델 레지스트리 배포 승인 흐름 개선 → ML팀과 협의.
- **도구**: Docker, Kubernetes, Kubeflow, MLflow, Airflow, KServe/Triton/vLLM, NVIDIA GPU Operator, Prometheus.
- **연봉**: 3~5년 6,000~9,000만+. 주니어 신입 공고는 매우 적음.
- **채용시장**: AI 기업·대형 IT·LLM 서비스 기업 중심. 수요는 증가 중이나 소수 정예. DevOps/ML 둘 다 알아야 해서 진입 장벽 높음.

## 3. 직무 간 겹침
```
        개발(Dev) ←――――――→ 운영(Ops)
 플랫폼 ── DevOps ── SRE ── 인프라 ── 클라우드
                                   ↘ MLOps (위 전부 + ML 지식)
```
실제 공고에서는 이름이 섞여서 쓰입니다. **직무명보다 JD(주요 업무·자격요건)를 읽는 습관**을 들이세요.

## 4. 내 조건에서의 추천 (직무 전환 + 기초 경험 있음)

### 추천 1순위: 클라우드/DevOps 엔지니어 (주니어)
- 이유: ① 진입 공고가 가장 많다 ② 03번 기술 스택(Linux, 네트워크, AWS, Docker, Terraform, CI/CD)이 그대로 요구 스펙 ③ 이후 SRE/플랫폼/MLOps로 분기하기 쉬운 "허브" 직무.
### 추천 2순위: 클라우드 MSP의 엔지니어 / 인프라 엔지니어(클라우드 병행)
- 이유: 주니어를 교육 포함해 채용하는 경우가 많고, 다양한 고객사 환경을 경험해 학습 속도가 빠름. 자격증(SAA 등)이 직접 평가 요소.
### 비추천(처음에): SRE, MLOps, 플랫폼 직행
- 경력 요구가 높음. 2~3년 뒤 이동하는 **목표 직무**로 두고, 지금은 포트폴리오 방향만 맞춰두세요.

### 선택 가이드
| 상황 | 추천 |
|---|---|
| 개발 경험(코딩) 있음 | DevOps → 플랫폼/SRE |
| 시스템/서버 경험 있음 | 인프라/클라우드 → SRE |
| 데이터/ML 관심 | 클라우드/DevOps → MLOps (1~3년 후) |
| 빠른 취업 최우선 | MSP 클라우드 엔지니어 |

## 5. 한국 채용시장 현실 정리
- 신입·주니어 전용 "순수 DevOps/SRE" 공고는 적고, 경력 요구가 많음 → **포트폴리오와 자격증으로 "경력 대체 신호"**를 만들어야 함.
- 공고 키워드 상위: AWS, Kubernetes, Terraform, Docker, CI/CD, Linux, Python, 모니터링.
- 채용 경로: 원티드, 사람인, 잡코리아, 점핏, 로켓펀치, 링크드인, 커뮤니티(OKKY, 페이스북 그룹), 지인 추천.
- 계약직/파견·야간 대기 있는 SI·유지보수 직무는 처우·성장 면에서 편차가 크니 업무 내용을 꼭 확인.
- 근무 형태(온콜 유무, 야간 작업 빈도)가 삶의 질을 크게 좌우 → 면접에서 질문하세요.
